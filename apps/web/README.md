# Zeno web

Next.js App Router application for the Zeno product landing page, public event discovery and reservations, the engineering demo, and organizer tools. Public event data and reservation behavior come from the Rust/Axum API; organizer pages require configured Neon Auth and tenant membership.

Run from the repository root with `bun run --filter @zeno/web dev`. Use the root commands for linting, type-checking, and production builds.
